# Documentation

Choose a guide for the task you want to do. For a product overview, see the [Atlas README](../README.md).

## New to Atlas

Start with [Getting started](getting-started.md) to understand the requirements, install Atlas when public downloads are available, and set up the helper account. Then use [Agent connections](agents.md) to connect your agent and check that it can reach Atlas.

## Using Atlas

[Using Atlas](using-atlas.md) walks through testing an app, watching the helper, taking control and stopping agent input. [Agent connections](agents.md) also covers refreshing a connection, project instructions and the viewing routes available in each host.

For exact command options, use `atlas --help` or the [bundled command reference](../agents/atlas/skills/atlas/references/commands.md). The [bundled troubleshooting reference](../agents/atlas/skills/atlas/references/troubleshooting.md) explains Atlas error codes and their next steps.

## Contributing

[Contributing](../CONTRIBUTING.md) covers building from source, the repository layout, required checks and testing against the real helper. Read the [security policy](../SECURITY.md) before reporting a security issue.
